# برنامج المبيعات 🛒

برنامج مبيعات ومخزون كامل يشتغل **لوكل (بدون إنترنت وبدون سيرفر)**، ومصمم يشتغل كويس على **الموبايل** والكمبيوتر.
كل البيانات بتتحفظ على نفس الجهاز داخل المتصفح.

## المميزات

- **نقطة بيع (كاشير):** بحث بالاسم أو الباركود (يدعم قارئ الباركود — امسح واضغط Enter)، تقسيم بالأقسام، تعديل الكمية والسعر، خصم بقيمة أو نسبة، ضريبة، دفع نقدي / فيزا / آجل، حساب الباقي.
- **الفواتير:** بحث وفلترة بالتاريخ والحالة، طباعة فاتورة حرارية 80مم، مشاركة على واتساب، مرتجع كامل (يرجّع المخزون ويعدّل حساب العميل)، تصدير Excel (CSV).
- **الأصناف والمخزون:** إضافة وتعديل وحذف، سعر شراء وبيع، أقسام، باركود، تنبيه عند نقص الكمية، إضافة/خصم مخزون مع متوسط التكلفة، أصناف خدمية بدون مخزون، قيمة المخزون.
- **المشتريات:** فواتير شراء من الموردين، خصم، دفع جزئي (آجل)، تحديث متوسط التكلفة تلقائيًا، مرتجع للمورد.
- **الموردين:** المستحق لكل مورد، سداد دفعات، كشف حساب.
- **المخزون:** أرصدة الأصناف وقيمتها، سجل كامل لحركة المخزون (بيع، شراء، مرتجع، تالف، جرد)، وجرد فعلي يسوّي الفروقات.
- **العملاء:** بيع آجل، رصيد مستحق، تحصيل دفعات، كشف حساب.
- **المصروفات:** تسجيل المصروفات بالبنود والتاريخ.
- **التقارير:** مبيعات، تكلفة، مجمل ربح، صافي ربح بعد المصروفات، رسم بياني يومي، الأكثر مبيعًا، طرق الدفع — لأي فترة.
- **الإعدادات:** بيانات المحل للفاتورة، العملة، الضريبة، الوضع الليلي، نسخ احتياطي واسترجاع (ملف JSON)، بيانات تجريبية.

## طريقة التشغيل

### على الكمبيوتر
افتح ملف `index.html` بأي متصفح (Chrome / Edge / Firefox) — خلاص.

### على الموبايل (نفس شبكة الواي فاي)
1. على الكمبيوتر شغّل: `python3 serve.py`
2. هيظهر لك لينك زي `http://192.168.1.5:8080` — افتحه من متصفح الموبايل.
3. من قائمة المتصفح اختار **"إضافة إلى الشاشة الرئيسية" / Install app** عشان يبقى زي التطبيق ويشتغل بعد كده من غير نت.

> أي استضافة ملفات ثابتة (GitHub Pages / Netlify) هتشتغل برضه — ارفع فولدر `sales-app` زي ما هو.

## ⚠️ مهم: النسخ الاحتياطي
البيانات محفوظة في المتصفح على الجهاز ده بس. لو مسحت بيانات المتصفح هتضيع.
خد **نسخة احتياطية** من الإعدادات بشكل دوري، وتقدر تسترجعها على أي جهاز تاني.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة والقوائم |
| `styles.css` | التصميم (متجاوب + وضع ليلي) |
| `app.js` | كل منطق البرنامج والبيانات |
| `sw.js` | تشغيل بدون إنترنت (عند الفتح عبر http) |
| `manifest.webmanifest`, `icon.svg` | تثبيت كتطبيق على الموبايل |
| `serve.py` | سيرفر محلي صغير لفتح البرنامج من الموبايل |
